# Phase 5 — theory clean-up

**Status: re-derived and numerically checked (exp35).**

This note fixes the statement and proof of Proposition 2 (surrogate regret), decides the
fate of the old download-charged regret bound (G3b), and defines the two quantities the
paper promises to measure in every run: the predictor bias `ζ` and the rounding
distortion `δ_t`.  It replaces the sketch in the working draft; the earlier draft's
`Theorem 1` / G3b is **not** claimed.

---

## 1. Setup and notation

There are `N` services and a resource matrix `A ∈ R^{m×N}` with entries
`a_{n,r} ∈ [0,1]`, and a capacity vector `b ∈ R^m_{>0}`.  The fractional cache polytope is

```
D_vec = { p ∈ [0,1]^N : A p ≤ b }.
```

Round `t = 1..T` a request `n*_t ∈ [N]` arrives.  The learner holds a state
`p_{t-1} ∈ D_vec` before the round and plays it.  The realized latency coefficient of the
request is

```
c_t = (1 - q_t) l_{n*_t} + q_t min(l_{n*_t}, dm_t)  ∈ [0, ℓ_max],
```

where `q_t = 1` iff a download of `n*_t` is already in flight, `dm_t` is the remaining
download time, `l_n` is the forwarding latency and `ℓ_max = max_n l_n`.  The learner forms
a surrogate coefficient `c~_t` (the gradient it actually uses) and updates

```
p_t = Π_{D_vec}( p_{t-1} + η c~_t e_{n*_t} ),        η > 0.
```

The surrogate loss is `F_t(p) = (1 - p_{n*_t}) c~_t`, with gradient
`∇F_t(p) = -c~_t e_{n*_t}` and `||∇F_t(p)||_2 = c~_t ≤ ℓ_max`.  The realized loss is
`L_t(p) = (1 - p_{n*_t}) c_t`.

`D_vec ⊆ [0,1]^N`, so `diam(D_vec) ≤ sqrt(N)`.

> **Indexing convention.**  The state *played* at round `t` is `p_{t-1}`; the state
> *after* the update is `p_t`.  The draft's Proposition 2(i) writes `P_t` in the inner
> product but its proof uses `p_{t-1}`.  The correct statement uses `p_{t-1}` throughout;
> the implementation's `peek=True` variant (update before serving) is an optimistic
> heuristic and is discussed in §4.

## 2. Proposition 2(i) — deterministic OGD regret

**Proposition 2(i).**  For every sequence `(n*_t, c~_t)` with `c~_t ∈ [0, ℓ_max]` and
every `P* ∈ D_vec`, projected OGD with step size `η` satisfies

```
Σ_t ⟨ ∇F_t(p_{t-1}), p_{t-1} − P* ⟩
    ≤ ||p_0 − P*||² / (2η) + (η/2) Σ_t ||∇F_t(p_{t-1})||²
    ≤ N/(2η) + (η/2) ℓ_max² T.
```

With `p_0 = 0` and `η = sqrt(N) / (ℓ_max sqrt(T))` the right-hand side is

```
sqrt(N) ℓ_max sqrt(T).
```

Equivalently, for the surrogate loss,

```
Σ_t F_t(p_{t-1}) − min_{P∈D_vec} Σ_t F_t(P) ≤ sqrt(N) ℓ_max sqrt(T).
```

**Proof.**  Put `g_t = ∇F_t(p_{t-1})`.  The update is
`p_t = Π(p_{t-1} − η g_t)`.  Euclidean projection onto a closed convex set satisfies
`||Π(z) − u||² ≤ ||z − u||²` for every `u` in the set.  Taking `z = p_{t-1} − η g_t` and
`u = P*`:

```
||p_t − P*||² ≤ ||p_{t-1} − P*||² − 2η ⟨g_t, p_{t-1} − P*⟩ + η² ||g_t||².
```

Rearranging and summing over `t` telescopes the first two terms:

```
Σ_t ⟨g_t, p_{t-1} − P*⟩
  ≤ (||p_0 − P*||² − ||p_T − P*||²)/(2η) + (η/2) Σ_t ||g_t||²
  ≤ ||p_0 − P*||²/(2η) + (η/2) Σ_t ||g_t||².
```

Since `p_0 = 0` and `P* ∈ [0,1]^N`, `||p_0 − P*||² = ||P*||² ≤ N`.  Since
`||g_t||² = c~_t² ≤ ℓ_max²`, the second display follows.  Substituting `η` gives the
stated `sqrt(N) ℓ_max sqrt(T)`.  ∎

**Remarks.**

1. The bound is deterministic: it holds for every realization of the requests and of the
   surrogate coefficients.  It is the standard OGD regret bound (Zinkevich, 2003;
   Hazan, 2016, §3.1).
2. The proof needs an **exact** Euclidean projection.  The implementation's dual ascent
   (`proj_tol = 1e-7`) matches the exact QP to ~1e-9 in exp07; the `proj_skip_tol` and
   `proj="scale"` variants are heuristics and add an `O(T ε_proj)` term that the bound
   does not include.
3. If the algorithm plays the **post-update** state `p_t` (the `peek=True` variant), the
   inner product above is not the one that the standard proof telescopes.  A crude bound
   adds `Σ_t ⟨g_t, p_t − p_{t-1}⟩ ≤ η ℓ_max² T`, i.e. another `sqrt(N) ℓ_max sqrt(T)`.
   The experiments below use the pre-update sequence, which is the object of the
   proposition.  The peeking variant is an optimistic heuristic; it is not claimed to
   satisfy the same bound a priori.

## 3. Proposition 2(ii) — realized regret under Assumption 1

**Assumption 1 (consistency).**  `q_t` and `dm_t` are `F_t`-measurable (they may depend on
`p_{t-1}`), and there is `ζ ≥ 0` with

```
| E[ c_t | F_{t-1} ] − c~_t | ≤ ζ        for all t,
```

where `F_t` is the σ-field generated by all internal randomness up to round `t`.  In words,
the learner's surrogate `c~_t` is within `ζ` of the conditional mean of the realized cost.

**Proposition 2(ii).**  Under Assumption 1,

```
E[ Σ_t L_t(p_{t-1}) ] − E[ min_{P∈D_vec} Σ_t L_t(P) ]
    ≤ 2 sqrt(N) ℓ_max sqrt(T) + ζ T.
```

**Proof.**  Decompose

```
c_t = c~_t + ζ_t + ε_t,
ζ_t = E[c_t | F_{t-1}] − c~_t        (|ζ_t| ≤ ζ),
ε_t = c_t − E[c_t | F_{t-1}]          (E[ε_t | F_{t-1}] = 0, |ε_t| ≤ ℓ_max).
```

Then, for any fixed `P*`,

```
Σ_t L_t(p_{t-1}) − L_t(P*)
  = Σ_t c_t (P*_{n*_t} − p_{n*_t,t-1})
  = Σ_t c~_t (P*_{n*_t} − p_{n*_t,t-1})                 [surrogate term]
  + Σ_t ζ_t (P*_{n*_t} − p_{n*_t,t-1})                  [bias term]
  + Σ_t ε_t (P*_{n*_t} − p_{n*_t,t-1}).                 [noise term]
```

*Surrogate term.*  Since `⟨∇F_t(p_{t-1}), p_{t-1} − P*⟩ = c~_t(P*_{n*_t} − p_{n*_t,t-1})`,
Proposition 2(i) gives

```
Σ_t c~_t (P*_{n*_t} − p_{n*_t,t-1}) ≤ sqrt(N) ℓ_max sqrt(T).
```

*Bias term.*  `|P*_{n*_t} − p_{n*_t,t-1}| ≤ 1`, so the bias term is at most `ζ T`.

*Noise term.*  Write

```
Σ_t ε_t (P*_{n*_t} − p_{n*_t,t-1})
  = − Σ_t ε_t p_{n*_t,t-1} + Σ_n P*_n S_n,
S_n = Σ_{t : n*_t = n} ε_t.
```

The first sum has zero mean because `p_{n*_t,t-1}` is `F_{t-1}`-measurable and
`E[ε_t | F_{t-1}] = 0`:

```
E[ ε_t p_{n*_t,t-1} ] = E[ p_{n*_t,t-1} E[ε_t | F_{t-1}] ] = 0.
```

For the second sum, the comparator may depend on the realized sequence, so we bound the
supremum inside the expectation:

```
E[ sup_{P*∈[0,1]^N} Σ_n P*_n S_n ]
  = E[ Σ_n max(S_n, 0) ]
  ≤ E[ Σ_n |S_n| ].
```

If the request sequence is exogenous, `T_n = {t : n*_t = n}` is deterministic and

```
E|S_n| ≤ sqrt(E[S_n²]) = sqrt(Σ_{t∈T_n} E[ε_t²]) ≤ ℓ_max sqrt(|T_n|).
```

Summing and applying Cauchy–Schwarz,

```
Σ_n E|S_n| ≤ ℓ_max Σ_n sqrt(|T_n|)
           ≤ ℓ_max sqrt(N) sqrt(Σ_n |T_n|)
           =  ℓ_max sqrt(NT).
```

If `n*_t` is `F_{t-1}`-measurable (adaptive but predictable), the same bound holds with
`T_n` a predictable random set: cross terms vanish because
`E[ε_t ε_s 1{t∈T_n} 1{s∈T_n}] = 0` for `t < s`, so
`E[S_n²] = E[Σ_{t∈T_n} ε_t²] ≤ ℓ_max² E|T_n|`, and
`Σ_n sqrt(E|T_n|) ≤ sqrt(NT)`.

The first sum has mean zero, so the noise term contributes at most `ℓ_max sqrt(NT)` in
expectation.  Combining the three terms gives

```
E[ Σ_t L_t(p_{t-1}) ] − E[ min_P Σ_t L_t(P) ]
  ≤ sqrt(N) ℓ_max sqrt(T) + ζ T + sqrt(N) ℓ_max sqrt(T)
  = 2 sqrt(N) ℓ_max sqrt(T) + ζ T.        ∎
```

**Remarks.**

1. The factor `2` is the sum of the OGD term and the martingale term.  It is **not** a
   peeking penalty; it comes from comparing the realized loss to the surrogate loss.
2. If `c~_t = c_t` (the `grad_mode="realized"` implementation), then `ζ_t = ε_t = 0` and
   the bound reduces to the one-term `sqrt(N) ℓ_max sqrt(T)`.  The `2x` factor is only
   needed when the learner uses an estimate (`grad_mode="expectation"`).
3. The proof assumes `n*_t` does not depend on the current-step cost noise `ε_t`.  In the
   simulator the trace is generated independently of the algorithm, so this holds.  An
   adversary that chooses `n*_t` after seeing `c_t` can break the martingale argument; the
   paper should state this explicitly.
4. The comparator is the best fixed `P` in hindsight for the realized loss.  It is a
   fractional comparator; it may cache instantly and therefore is not a download-aware
   benchmark.  The literal realized-latency regret (with the same fractional comparator)
   is much larger in exp09; see §5.
5. The bound is in expectation over the algorithm's randomness and the cost noise.  A
   single run may exceed it; exp35 reports the empirical hold rate over seeds.

## 4. What Proposition 2 does and does not say

**It says:** the surrogate regret of the pre-update OGD sequence is
`O(sqrt(N) ℓ_max sqrt(T))`, and the realized regret to the best fixed fractional cache is
`O(sqrt(N) ℓ_max sqrt(T) + ζ T)`.

**It does not say:**

- it is a competitive ratio against an offline optimum that pays download costs;
- it covers the *realized latency* (hits, delayed hits, forwards) — that is a different
  loss, and the fractional comparator is unrealistically strong because it can cache
  instantly;
- it covers the download budget or the repair rule;
- it holds for an adaptive adversary that chooses the request after seeing the current
  cost realization;
- it holds for the peeking implementation without the extra term of §2 remark 3.

The paper should state the proposition as a **surrogate regret** statement, not as a
competitive-ratio theorem.  The draft already does this in Remark 1(1); Phase 5 keeps that
honest framing.

## 5. The G3b download-charged bound: decision — remove it

The old draft's `Theorem 1` claimed a bound of the form

```
E[latency + downloads]
  ≤ min_P [ Σ_t F~_t(P) + Σ_n M_n P_n ]
    + 2 sqrt(N) ℓ_max sqrt(T) + ζ T + ℓ_max Σ_t δ_t + M_max N sqrt(T).
```

The last term was meant to cover repair-induced fetches.  It is **not justified**:

- Lemma 3 of the draft bounds only the *rounding* churn: for the coupling
  `x_{k,n,t} = 1[U_{k,n} < p_{n,t}]`,
  `Pr[x_{k,n,t-1}=0, x_{k,n,t}=1] = (p_{n,t} − p_{n,t-1})_+`, and
  `Σ_t P_n M_n Pr[...] ≤ M_max N p_T`.
- A repair eviction can remove a service that the next draw would have kept.  The next
  request for that service then triggers a **new download** even though the rounding
  coupling did not predict it.  Lemma 3 does not count these fetches.
- The draft's `M_max N sqrt(T)` term has no derivation covering the repair-induced
  refetches; it is a placeholder.  The working draft already says this in Remark 1(2):
  "a download-charged regret bound ... would need a churn bound that covers
  repair-induced fetches; an earlier draft stated such a bound as a theorem with a sketch
  only, and it is not claimed here."

**Decision.**  Remove G3b as a claimed theorem.  Keep `sim/regret_bound.py` as a
**diagnostic** only.  The paper should say the download-charged regret is open, and should
report the measured components (rounding churn and repair-induced fetches) rather than a
fake bound.

**Measured gap (exp35, N=40, T=8000, 10 seeds, `gate_downloads=False`).**

| repair rule | repair evictions | repair-evicted requests | repair-induced refetches | refetch cost | rounding churn (`Σ_t δ_churn`) |
|---|---:|---:|---:|---:|---:|
| stateless | 18,740 | 283.7 | 45.3 | 6,352 | 154.3 |
| Landlord | 21,811 | 556.7 | 42.0 | 5,992 | 651.7 |

The repair-induced refetches are a non-negligible fraction of the rounding churn
(~29% for stateless, ~6% for Landlord) and are not covered by Lemma 3.  With the default
download gate on, they are zero by construction: a download can only start if the serving
sample contains the service, and a repair eviction removes it.  The paper should report
the gate as the mechanism that prevents repair-induced fetches, and should report the
gate-off numbers as the cost of the literal Algorithm 1.

## 6. `ζ` and `δ_t`: definitions and measurement

### 6.1 Predictor bias `ζ`

The proposition needs a bound on `|E[c_t | F_{t-1}] − c~_t|`.  In a run we do not observe
the conditional expectation, so we report three empirical quantities:

- **signed bias** `ζ_signed = mean_t (c_t − c~_t)`.  If `c~_t` is `F_{t-1}`-measurable,
  this is an unbiased estimate of the bias.  For `grad_mode="realized"` it is exactly 0;
  for `grad_mode="expectation"` it is the mean EMA error.
- **mean absolute error** `ζ_mae = mean_t |c_t − c~_t|`.  This upper-bounds the absolute
  bias and is the quantity used in the `ζ T` term of Proposition 2(ii).
- **one-step predictor MAE** `ζ_pred_mae = mean_t |c_t − c_pred,t|`, where
  `c_pred,t = (1 − q_ema,t−1) l_n + q_ema,t−1 min(l_n, dl_ema,t−1)` is the `F_{t-1}`-predictable
  EMA predictor.  This is a diagnostic of how well the EMA tracks the realized cost, even
  when the algorithm uses the realized gradient.

All three are logged per step (`c_realized`, `grad`, `c_pred`, `zeta`, `zeta_pred`) and
summarized in `diagnostics()` (`mean_zeta`, `mean_abs_zeta`).  `regret_bound_terms()`
returns `zeta_signed`, `zeta_mae`, `zeta_pred_mae`.

**Measured values (exp35, N=40, T=8000, 10 seeds).**

| grad mode | repair rule | ζ_signed | ζ_mae | ζ_pred_mae |
|---|---|---:|---:|---:|
| realized | stateless | 0.000 | 0.000 | 0.000 |
| realized | Landlord | 0.000 | 0.000 | 0.000 |
| expectation | stateless | −0.049 | 0.049 | 0.049 |
| expectation | Landlord | −0.288 | 0.289 | 0.289 |

The negative sign means the EMA predictor overestimates the realized cost on average
(grad > c_realized).  The bias is small relative to `ℓ_max` (≈ 21 ms in this world), but
the `ζ T` term is `O(T)` and is the reason the general bound is not `o(T)` unless the
predictor is consistent.

### 6.2 Rounding distortion `δ_t`

Three quantities are logged per step:

- `delta_l1_t = ||p_t − p_{t-1}||_1` — the L1 movement of the fractional state caused by
  the OGD update.  This is the quantity that controls the rounding churn through Lemma 3.
- `delta_round_t = |p_{n*_t,used} − x_{k*,n*_t,t}|` — the per-request rounding error
  between the fractional state used for the decision and the rounded bit.
- `delta_churn_t = 1[x_{k*,n*_t}(t-1)=0, x_{k*,n*_t}(t)=1]` — the realized 0→1
  transition for the requested service; `delta_churn_all_t` counts all 0→1 transitions on
  the served path.

`diagnostics()` reports `mean_delta_l1`, `mean_delta_round`, `delta_churn_sum`,
`delta_churn_all_sum`.  `regret_bound_terms()` reports the same as `delta_l1_mean`,
`delta_round_mean`, `delta_churn_rate`, `delta_churn_sum`, `delta_churn_all_sum`.

**Measured values (exp35, N=40, T=8000, 10 seeds).**

| grad mode | repair rule | mean δ_l1 | mean δ_round | δ_churn rate | Σ δ_churn_all |
|---|---|---:|---:|---:|---:|
| realized | stateless | 0.0769 | 0.106 | 0.0155 | 154.3 |
| realized | Landlord | 0.0767 | 0.199 | 0.1067 | 651.7 |
| expectation | stateless | 0.0772 | 0.105 | 0.0151 | 154.3 |
| expectation | Landlord | 0.0772 | 0.196 | 0.1071 | 651.7 |

The stateless repair has much lower rounding distortion and churn than the Landlord
repair on this workload, consistent with the Phase-2 utilization result.  The `δ_l1` mean
is similar because it is driven by the OGD step size, not by the repair rule.

### 6.3 Lemma 3 (rounding churn) — re-derived

With the coupling `x_{k,n,t} = 1[U_{k,n} < p_{n,t}]` and an exact projection,

```
Pr[x_{k,n,t-1}=0, x_{k,n,t}=1] = (p_{n,t} − p_{n,t-1})_+.
```

Since `p_t, p_{t-1} ∈ D_vec` and the projection is nonexpansive,
`||p_t − p_{t-1}||_2 ≤ η c~_t ≤ η ℓ_max`, so `||p_t − p_{t-1}||_1 ≤ sqrt(N) η ℓ_max`.
With `η = sqrt(N)/(ℓ_max sqrt(T))`, the per-step L1 churn is at most `N/sqrt(T)`, and

```
Σ_t Σ_n M_n Pr[x_{k,n,t-1}=0, x_{k,n,t}=1]
  ≤ M_max Σ_t ||p_t − p_{t-1}||_1
  ≤ M_max N sqrt(T).
```

This is the draft's Lemma 3.  It bounds **rounding churn only**.  The repair-induced
refetches in §5 are additional and are not covered.

## 7. Numerical verification (exp35)

`python experiments/exp35_phase5_theory_check.py` (full: N=40, T=8000, 10 seeds) reports:

| quantity | realized/stateless | realized/Landlord | expectation/stateless | expectation/Landlord |
|---|---:|---:|---:|---:|
| surrogate regret | 3,883 | 3,859 | 3,891 | 3,891 |
| Prop. 2(i) bound `sqrt(N) ℓ_max sqrt(T)` | 11,879 | 11,879 | 11,879 | 11,879 |
| realized regret | 3,883 | 3,859 | 3,869 | 3,826 |
| Prop. 2(ii) bound `2·bound + ζ_mae T` | 23,759 | 23,759 | 24,151 | 26,070 |
| surrogate / bound | 0.327 | 0.325 | 0.327 | 0.327 |
| realized / bound | 0.163 | 0.163 | 0.160 | 0.147 |
| hold rate (surrogate) | 1.00 | 1.00 | 1.00 | 1.00 |
| hold rate (realized) | 1.00 | 1.00 | 1.00 | 1.00 |

The deterministic Proposition 2(i) check (5 random exogenous sequences) also holds on
every trial (regret ≈ 0.35–0.38 of the bound).

**Interpretation.**

- The surrogate regret is about one third of the Proposition-2(i) bound in every
  configuration.  The bound is valid but loose.
- The realized regret is about one sixth of the general Proposition-2(ii) bound.  For
  `grad_mode="realized"` it equals the surrogate regret, as expected (`c~_t = c_t`).
- The `ζ_mae T` term is small for the stateless repair (0.049 × 8000 ≈ 393) and larger
  for the Landlord repair (0.289 × 8000 ≈ 2,311), but it is still much smaller than the
  `2 sqrt(N) ℓ_max sqrt(T)` term (≈ 23,759).  The bound is dominated by the OGD term, not
  by the predictor bias, in this world.
- The measured `ζ` is small relative to `ℓ_max`, but the theory only needs it to be
  `o(1)` for the regret to be `o(T)`.  The EMA tracking experiment (exp24) suggests the
  optimal smoothing rate grows with drift and shrinks with noise, but this is a
  simulation, not a proof.

## 8. Open items and threats to validity

1. **Adaptive adversary.**  Proposition 2(ii) requires `n*_t` not to depend on the
   current cost noise `ε_t`.  The paper should state this and either restrict the
   adversary to oblivious/predictable request sequences or add a term for the adaptive
   case.
2. **Peeking implementation.**  The default `peek=True` updates before serving.  The
   proposition is stated for the pre-update sequence.  A full proof for the peeking
   variant needs the extra `Σ_t ⟨g_t, p_t − p_{t-1}⟩` term of §2 remark 3.  The
   experiments use the pre-update sequence; the paper should either switch to
   `peek=False` for the theory runs or state the gap.
3. **Projection error.**  The bound assumes exact projection.  The dual-ascent projection
   is exact to ~1e-9 (exp07), but `proj_skip_tol` and `proj="scale"` are not covered.
4. **Download-charged regret.**  G3b is removed.  A proper bound would need a churn
   analysis that includes repair-induced fetches; the measured gap is reported in §5.
5. **Comparator strength.**  The fractional comparator can cache instantly; it is not a
   download-aware benchmark.  The literal realized-latency regret (exp09) is 3–10x the
   bound and grows with `T`.  The paper must not present Proposition 2 as a
   competitive-ratio result.
6. **Constant factors.**  The bound's constants are not optimized; the empirical ratio
   ~0.33 suggests room for a tighter analysis, but no claim is made.

## 9. Recommended paper text

> **Proposition 2 (surrogate regret).**  Let `η = sqrt(N)/(ℓ_max sqrt(T))` and let
> `L_t(P) = (1 − p_{n*_t}) c_t` be the loss with the realized cost.  (i) For every
> realization, the pre-update projected-OGD sequence satisfies
> `Σ_t ⟨∇F_t(p_{t-1}), p_{t-1} − P*⟩ ≤ sqrt(N) ℓ_max sqrt(T)`.  (ii) Under Assumption 1,
> `E[Σ_t L_t(p_{t-1})] − E[min_P Σ_t L_t(P)] ≤ 2 sqrt(N) ℓ_max sqrt(T) + ζ T`.  The
> regret is therefore `o(T)` if the predictor bias `ζ` vanishes; a persistent bias yields
> linear regret.
>
> **Remark (what is not proved).**  (1) No competitive-ratio bound is proved; the flat
> ratio in Section 6 is empirical on constructed families.  (2) A download-charged regret
> bound for realized latency plus downloads would need a churn bound that covers
> repair-induced fetches; an earlier draft stated such a bound as a theorem with a sketch
> only, and it is not claimed here.  (3) Assumption 1 is not shown to hold; the EMA
> tracking experiment suggests the best smoothing rate grows with drift and shrinks with
> noise, but this is a simulation, not a proof.
